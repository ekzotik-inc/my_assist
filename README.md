# AI-ассистент для Telegram Business

Бот отвечает клиентам в твоих бизнес-чатах (Telegram для бизнеса) **от твоего
имени**, используя ИИ-модель.

## ⚠️ Безопасность

Никогда не коммить реальные ключи. Они хранятся только в файле `.env`, который
исключён из git (см. `.gitignore`). Если ключ где-то засветился — **сразу
перевыпусти его**:
- Токен бота: [@BotFather](https://t.me/BotFather) → `/revoke`
- Ключ ИИ: в панели провайдера.

## Что нужно

- Python 3.10+
- **Telegram Premium** на аккаунте, к которому подключаешь бота (требование
  Telegram для бизнеса).
- Бот, созданный через [@BotFather](https://t.me/BotFather).
- Ключ ИИ-провайдера (OpenAI-совместимый API).

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env      # впиши свои значения в .env
python bot.py
```

## Настройка `.env`

| Переменная           | Описание                                                        |
|----------------------|-----------------------------------------------------------------|
| `TELEGRAM_BOT_TOKEN` | Токен бота из @BotFather                                        |
| `AI_API_KEY`         | Ключ ИИ-провайдера                                              |
| `AI_BASE_URL`        | Базовый URL API (по умолчанию `https://console.openmodel.ai/v1`)|
| `AI_MODEL`           | Имя модели, например `deepseek-v4-flash`                        |
| `SYSTEM_PROMPT`      | Инструкция для ассистента — как себя вести                      |
| `HISTORY_LIMIT`      | Сколько последних пар реплик помнить                            |

> Если ИИ-запросы возвращают ошибку — проверь `AI_BASE_URL` в панели провайдера.
> Код рассчитан на OpenAI-совместимый эндпоинт `/chat/completions`.

## Подключение к Telegram Business

1. Запусти бота: `python bot.py`.
2. На телефоне: **Настройки → Telegram для бизнеса → Чат-боты**.
3. Укажи юзернейм своего бота и выдай ему права на ответы.
4. Напиши в свой бизнес-аккаунт с другого аккаунта — ассистент ответит сам.

## Как это работает

- Клиент пишет в твой бизнес-чат → Telegram присылает боту апдейт
  `business_message`.
- Бот шлёт текст в ИИ-модель (с учётом истории диалога).
- Ответ отправляется клиенту с параметром `business_connection_id` — то есть
  **от твоего имени**, а не от бота.
