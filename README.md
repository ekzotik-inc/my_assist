# AI-ассистент для Telegram Business (персона «Денис»)

Бот отвечает клиентам в твоих бизнес-чатах (Telegram для бизнеса) **от твоего
имени**, используя ИИ-модель DeepSeek V4 Flash через OpenModel.

Особенности:
- **Знания о тебе** и кейсы лежат в `cases.txt` — обычный текстовый файл.
- **Обновление на лету:** правишь `cases.txt` — бот подхватывает изменения без
  перезапуска (или командой `/reload`).
- **Самообучение:** бот сам записывает новые полезные факты из диалогов в
  `memory.jsonl` и использует их в следующих ответах. Можно учить и вручную.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env      # впиши свои значения в .env
python bot.py
```

## Настройка `.env`

| Переменная           | Описание                                                        |
|----------------------|-----------------------------------------------------------------|
| `TELEGRAM_BOT_TOKEN` | Токен бота из @BotFather                                        |
| `AI_API_KEY`         | Ключ OpenModel                                                  |
| `AI_BASE_URL`        | Базовый URL API (по умолчанию `https://api.openmodel.ai`)      |
| `AI_MODEL`           | Имя модели, например `deepseek-v4-flash`                        |
| `OWNER_ID`           | Твой Telegram user id — только ты управляешь обучением          |
| `AUTO_LEARN`         | `1` — бот учится сам, `0` — выключить                           |
| `SYSTEM_PROMPT`      | Базовый стиль/персона (подробности — в `cases.txt`)            |
| `HISTORY_LIMIT`      | Сколько последних пар реплик помнить в диалоге                  |

> `OWNER_ID` узнаешь у бота [@userinfobot](https://t.me/userinfobot).

## Как обновлять данные о себе

1. Открой `cases.txt`, отредактируй кейсы/правила, сохрани.
2. Изменения применятся автоматически на следующем сообщении.
   Хочешь сразу — отправь боту команду `/reload`.

## Самообучение

Бот после каждого диалога решает, есть ли там новое переиспользуемое знание, и
если да — сохраняет его в `memory.jsonl`. Выученные факты имеют приоритет над
базой и подмешиваются в системный промпт.

Команды владельца (писать боту в личку, работают только при заданном `OWNER_ID`):

| Команда           | Действие                          |
|-------------------|-----------------------------------|
| `/learn <текст>`  | Запомнить факт вручную            |
| `/memory`         | Показать выученные факты          |
| `/forget`         | Очистить всю выученную память     |
| `/reload`         | Перечитать `cases.txt`            |

> ⚠️ Это «обучение» = персистентная память (файлы), а не дообучение весов
> модели. Веса бесплатной модели мы не меняем — но на практике память даёт тот
> же эффект: бот помнит твои правила и накопленные кейсы между перезапусками.

## Файлы

| Файл            | Назначение                                              |
|-----------------|---------------------------------------------------------|
| `bot.py`        | Логика бота                                             |
| `cases.txt`     | База знаний и кейсов (персона) — правишь руками          |
| `memory.jsonl`  | Память самообучения (создаётся сама, в git не попадает)  |
| `.env`          | Ключи и настройки (в git не попадает)                    |

## Подключение к Telegram Business

1. Запусти бота: `python bot.py`.
2. На телефоне: **Настройки → Telegram для бизнеса → Чат-боты**.
3. Укажи юзернейм бота и выдай ему права на ответы.
4. Напиши в свой бизнес-аккаунт с другого аккаунта — ассистент ответит сам.
